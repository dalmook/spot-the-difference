# 작은 탐정단 · Little Detective Club

아이와 가족이 함께 즐기는 동화 일러스트 틀린그림 찾기 게임입니다.

**플레이:** https://dalmook.github.io/spot-the-difference/

- **108개 독립 장면, 216장 A/B 게임 이미지, 540개 정답**
- 숲속 소풍·바닷속·고양이 빵집·공룡·우주·사탕·농장·마법 성·눈꽃 마을·캠핑·장난감·보물섬: 12개 테마 × 9스테이지
- 느긋하게(무제한), 모험(150초/하트5), 챌린지(90초/하트3)
- 8초 연속 발견 콤보, 별1–3개, 코인, 단계 해금
- 매일 다른3스테이지 도전, 일일 미션, 출석 보상
- 여행 스티커12종, 탐정 배지8종, 기기별 최근 기록
- 무료 힌트3개/판, 추가 힌트25코인, 시간 정지12초, 동기화 확대/위치 이동
- 터치·마우스·키보드 지원, 효과음·진동·애니메이션 설정
- 로컬 자동 저장, JSON 백업·복구, 방문한 게임 이미지의 오프라인 캐시
- 광고·로그인·인앱결제·분석 추적·외부 CDN 없음

## 실행

Node.js20이상에서 별도 npm 패키지 설치 없이 실행합니다.

```bash
npm run dev
# http://localhost:4173
npm test
npm run check
npm run build
```

`index.html`을 파일로 직접 열면 모듈·JSON 로딩이 차단될 수 있으므로 위 웹서버를 이용하세요. GitHub Pages는 main 브랜치 루트에서 배포하며 `.nojekyll`이 포함되어 있습니다. `npm run build`는 다른 정적 호스팅용 `dist/`를 만듭니다.

## 게임 규칙

두 그림 중 아무 쪽에서나 차이를 클릭합니다. 다섯 곳을 모두 찾으면 완료합니다. 시간 모드에서 오답은 하트1개와3초를 차감합니다. 이미 찾은 정답은 다시 눌러도 차감되지 않습니다. 도움말·설정·일시 정지·탭 숨김 동안 타이머가 멈춥니다.

실수0·힌트0은 별3개, 실수와 힌트가 각각2개 이하이면 별2개, 그 외는 별1개입니다. 최초 완료 보상은25+별×8코인입니다. 재도전은8코인+새로 개선한 별×8코인입니다. 테마별 별6개를 모으면 스티커를 얻습니다. 각 테마의 첫 그림은 처음부터 열려 있고 이후 그림은 순서대로 열립니다.

모든 저장은 **현재 기기의 현재 브라우저**에만 남습니다. 계정 동기화나 온라인 순위는 없습니다. 브라우저 데이터를 삭제하면 기록이 사라지므로 설정의 기록 내보내기를 이용하세요. 오프라인에서는 앱과 캐시된 최근 이미지(최대60장)에 한해 이용 가능하며 미방문 그림은 인터넷이 필요합니다.

키보드: Tab으로 그림 선택 → 방향키 이동 → Enter/Space로 선택. H 힌트 / Z 확대 / P·Esc 정지. 모달은 포커스를 유지합니다. 감소된 모션 설정을 존중합니다.

## 원화와 정답 데이터

이번 프로젝트를 위해 생성한12개 원화 시트에 각각9개의 서로 다른 장면이 있습니다. 각 장면을 독립 파일로 분리해 `assets/scenes/001-a.webp`부터 `108-a.webp`까지 저장했습니다. 대응되는 `-b.webp`는 색·무늬가 바뀐 게임 화면이며, 정답 위치는 `assets/levels.json`에 정규화 좌표로 포함됩니다. 같은 원화를 단순 재색칠해108개 장면으로 세지 않습니다.

원화 생성 프롬프트: `art-prompts.json`.

`build-scenes.mjs`는 색상 연결 영역을 찾아, 영역 내부에 결정적 색상/무늬 게임 효과를 적용합니다. 각 스테이지의 정답5개는 서로 겹치지 않으며 변경 픽셀 수·색 차이를 검사합니다. 원화와 게임 화면은 lossless WebP로 보관하므로 이미지 압축 노이즈가 가짜 차이를 만들지 않습니다. 목록은 작은 미리보기 이미지로 로드합니다.

선택적으로 원화 시트를 다시 컴파일하려면 `sharp`를 설치하고 아래 명령을 실행하세요. 앱 실행·빌드·검사에는 sharp가 필요 없습니다.

```bash
npm install --no-save sharp
node scripts/build-scenes.mjs /path/to/game-art
node scripts/thumbnails.mjs
npm run check
```

## 구조

- `app.js`: 화면·게임 진행·오디오·대화상자·오프라인 등록
- `core.js`: 저장 검증·보상·판정·일일 도전·업적
- `style.css`: 반응형 화면·확대·보상 애니메이션
- `assets/levels.json`:108개 스테이지와540개 정답
- `assets/scenes/`:216개 게임 이미지
- `assets/thumbs/`:108개 작은 미리보기
- `tests/core.test.mjs`: 저장 오류·일일 도전·해금·보상·판정 검증
- `scripts/validate.mjs`: 이미지 수·고유성·정답 수·영역 충돌 검사
- `sw.js`: 앱 캐시와 최근 이미지 캐시

## 개인정보

서버로 게임 기록을 전송하지 않습니다. 내보내기는 사용자의 다운로드, 불러오기는 사용자가 선택한 로컬 JSON 파일만 사용합니다. JSON 기록의 사용자 문자열을 HTML로 삽입하지 않습니다.
